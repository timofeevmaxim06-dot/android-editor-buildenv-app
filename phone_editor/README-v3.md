# Godot Phone Preview 3.2

Экспериментальная версия редактора для Redmi Note 13 ARM64. Обновляет Preview 3.1:
пакет `org.godotengine.editor.v4.phonepreview31.debug` и закреплённая тестовая
подпись сохранены. Принятая Preview 3 остаётся отдельным приложением.
Первое испытание — на копии проекта.

## Исправления по записи 14 сентября 2026 года

1. Однопальцевая прокрутка кода выбирает ось по началу жеста. Небольшой боковой
   уход при вертикальном движении не сдвигает текст. Намеренное горизонтальное
   движение остаётся доступным. Это работает в обычном вводе и режиме «Листать»;
   маркеры выделения и двухпальцевые жесты обрабатываются отдельно.
2. На постоянной строке кода: «Вставить», отмена ↶, ←/→, А+ и ⋮. Остальные команды
   открываются через ⋮, переносятся по ширине и закрываются после выбора.
   «Перенос строк» меняет только отображение и сохраняет настройку; исходный текст,
   выделение, история отмены и незавершённый ввод не переписываются.
   Кнопка ☰ перед общей полосой вкладок открывает список доступных разделов.
   Список скриптов при недостаточной ширине располагается над кодом; при повороте
   раскладка пересчитывается, чтобы закреплённые команды не уходили за экран.
3. Android-окно игры при открытии, восстановлении, перетаскивании, изменении
   размера, повороте и возврате из полноэкранного режима вписывается в актуальную
   доступную область. Полноэкранный режим и закрытие закреплены справа; остальные
   команды находятся в прокручиваемой части. Старые координаты за экраном
   ограничиваются допустимыми, геометрия не берётся из кеша прошлой ориентации.
4. В 2D доступны «Выбор», «Обзор» (перемещение вида пальцем без выбора объекта)
   и «Кадр»: к выделенному, вписать выделенное, показать всю сцену. Команды меняют
   вид редактора, а не положение объектов.
5. «Инспектор», «Сигналы» и «Группы» показывают выбранный в сцене узел или сообщение
   об отсутствии выбора. «Выбрать узел» возвращает к дереву сцены.

Основа этого обновления — рецепт `fa8d989724d21cfa3b53012b6c26a9399a1dc5f2`.
Содержимое игры и проектные реестры в этот рецепт не входят.

После проверки `34862011306` исправлены продолжение старой инерции при входе
в «Листать» и переполнение при открытом списке скриптов. Проверка меню направляет
ввод через оконный обработчик и проверяет единственный сигнал выбранного пункта.
Прямой `PopupMenu.push_input` обходил этот обработчик, вызывая ложные ошибки меню.

Проверки: реальная компиляция общего редактора; нажатия и события касания при
150%/200% в двух ориентациях; сохранность текста/истории при прокрутке и переносе;
работа основных и дополнительных команд; навигация и контекст узла; перемещение
2D-вида без изменения объекта. Android-задача отдельно компилирует Kotlin/Java и
выполняет JUnit-проверки геометрии окна, затем собирает ARM64 APK и проверяет подпись.
Фактический результат определяется итогом соответствующего запуска, не этим списком.
Системная клавиатура, фактическая оконная раскладка Android и удобство на Redmi
окончательно проверяются на устройстве.

## Предыдущее обновление 3.1 (история)

Принятая основа: рецепт `8eaf062308d0650e441f3d831ff373fd4c969d90`,
успешный запуск [34787328116](https://github.com/timofeevmaxim06-dot/android-editor-buildenv-app/actions/runs/34787328116).
В версии 3.1 расположение инструментов было сохранено. В конец прокручиваемой панели
кода добавлены **А−**, **А+** и **100%**. Прокрутите ряд команд влево до конца:
новые кнопки находились после «Скрипты». В 3.2 используется строка с меню ⋮,
описанная выше.

- **А− / А+** уменьшают или увеличивают только шрифт кода на один шаг.
- **100%** возвращает размер, заданный в настройках редактора.
- Кнопки используют штатный масштаб ScriptEditor. Они не вставляют и не
  подтверждают незавершённый ввод, не забирают фокус, не сбрасывают выделение
  и не выключают режим «Листать».
- Смена ориентации не сбрасывает масштаб. Его сохранение при обычном закрытии
  проекта использует штатную запись раскладки ScriptEditor.

### Размер текста в уже установленной Preview 3

Пересборка для настройки размера не требуется:

1. Если верхнее меню скрыто, нажмите «Панели» в строке команд кода.
2. Откройте «Редактор» → «Настройки редактора…».
3. Найдите «Размер шрифта кода» (Interface → Editor → Fonts → Code Font Size).
   Для начала попробуйте **18** вместо исходных **14**, затем подберите по глазам.
4. Если мелки именно подписи интерфейса, отдельно подберите «Размер основного
   шрифта» (Main Font Size), например **16**. Общий масштаб интерфейса для этого
   менять не требуется.

Настройки находятся в самом редакторе; они не меняют файлы игры. В Preview 3.1
можно вместо открытия настроек нажимать А+ непосредственно в коде.

### Установка и подпись

Прежний ключ подписи Preview 3 не сохранён. Поэтому Preview 3.1 имеет отдельный
идентификатор и не требует удаления принятой версии. Настройки приложений
раздельные; рабочего проекта новая установка сама не изменяет.

Для 3.1 workflow явно использует штатный публичный тестовый keystore из точной
базы Godot. Отпечаток сертификата проверяется при каждой сборке:
`921564d50b125fc1dfbe2209be475ed2172adf8be7f472532f212819715d3e8c`.
Это подпись для тестовых сборок, не релизный ключ. Рецепт позволяет повторять
её без случайной генерации другого сертификата при следующей сборке 3.1.

## Изменения

- Общая прокручиваемая полоса для 2D, 3D, Script, сцены, файлов, инспектора,
  сигналов, групп, импорта и истории. Каждый инструмент получает центральную
  рабочую область. Внутренний дублирующий ряд вкладок скрыт.
- Штатная регистрация панелей, ограничения профиля редактора и сохранение
  раскладки остаются у DockManager. Навигация доступна в режиме кода.
- Перенесена реализация сенсорного TextEdit/CodeEdit из Godot #119706 вместе
  с Android-обработчиками и JNI: касание ставит курсор, движение прокручивает,
  двойное касание выделяет слово; доступны маркеры выделения и инерция.
  Выбор слова использует координаты касания, независимо от положения мыши.
- Сохранены прямые команды вставки, вырезания, отмены/повтора, выбора строки,
  движения курсора, синхронизация открытой клавиатуры и отдельный режим чтения.
- Панели инструментов 2D/3D переносят элементы на узком экране.
  Строка состояния кода прокручивается и не растягивает редактор при открытом
  списке скриптов. В компактном коде строка состояния скрыта; «Панели»
  возвращает её вместе с меню. Окно принимает размер экрана без увеличения
  под содержимое.
- В окне создания узлов поиск, избранное и недавние элементы открываются
  отдельными вкладками. Сохранённый размер окна не мешает смене ориентации.
- Сам редактор допускает портретную ориентацию; верхнее меню прокручивается.

## Проверки

Workflow сначала проверяет исходники, затем компилирует общий код редактора.
Далее на Linux проверяются реальные нажатия по общим вкладкам, переключение
нативных панелей, отсутствие второго ряда вкладок, размеры рабочей области
при 150%/200% в горизонтальном и вертикальном окне, команды редактирования,
поданные события касания/движения, выделение слова и окно создания узлов.
Только после этого начинается Android-компиляция и упаковка APK.

Для 3.1 добавлены реальные нажатия мышью и события касания по А−/А+/100%:
рост и возврат шрифта, сохранность текста, курсора, выделения, undo/redo,
буфера обмена, фокуса и режима чтения. Проверяется смена ориентации с увеличенным
шрифтом и сохранение размеров рабочей области.

Проверки Linux не доказывают работу Android IME, системного буфера обмена и
сенсорного ввода на Redmi. Их нужно подтвердить на телефоне. Фактический итог
каждой сборки определяется журналом и артефактами соответствующего запуска.

R3-09 остаётся на паузе. Рабочая игра, GABE и проектные реестры не изменяются.

# Godot Phone Preview 1 — первая проверочная сборка

Работа только с Android-редактором. Игра, её ключ, GABE, основная ветка,
старый SAF-тест и R3-09 не изменяются. Это не готовая мобильная переработка.

## Зафиксированная основа

- Godot 4.7.2 stable: `ed1daf0bf001b61586d9930840f2f1394092c079`.
- Сборочная обвязка начинается от `d8702d74825cc975153c073d8aa5a20c0a17d9f0`.
- Прежняя рабочая сборка: GitHub Actions `34400717597`; её файлы не заменяются.
- Новая ветка: `phone-editor-preview-20260912`.
- Java 17, SCons 4.8.1, SDK 36, Build Tools 36.1.0, NDK 29.0.14206865.
- Gradle и AGP берутся из зафиксированного Godot, действия GitHub закреплены SHA.
- Сборка повторяема по рецепту; побайтовая воспроизводимость APK не доказана.
  Версия образа GitHub и фактические версии инструментов сохраняются в отчёте.

## Что меняется

1. Стандартные Button (включая наследников), LineEdit и строки Tree получают
   минимальные реальные размеры под палец: по умолчанию 48 dp, с пересчётом
   через Android densityDpi. Шрифт при этом не растягивается.
2. Увеличиваются высота Inspector, строк всплывающих меню и фонов вкладок.
   Это ещё не гарантия размера всех вложенных значков, стрелок и специальных
   инструментов: их нужно проверять отдельно.
3. Двухпальцевая прокрутка TextEdit/CodeEdit пересчитывается из входных единиц
   Android в пиксели и строки; убран чрезмерный горизонтальный коэффициент.
   Настройка чувствительности — от 25 до 200%, по умолчанию 100%.
4. Верхняя панель помещается в горизонтальную прокрутку. Кнопки сохраняют
   исходную обработку событий; глобального переключения MouseFilter нет.
5. Редактор обращается к ранее проверенной GABE с суффиксом `.saftest`.

Изменения размеров и прокрутки в общих GUI-классах ограничены Android,
редакторским режимом и константами редакторской темы. Шаблоны экспорта не
пересобираются; управление экспортированной игры не меняется.

В настройках редактора: `interface/touchscreen/phone_target_size_dp`,
`phone_text_pan_percent`, `phone_scrollable_top_bar`. После изменения перезапустить
редактор. Отключение `enable_touch_optimizations` и перезапуск отключают новые
размеры и пересчёт текстовой прокрутки; верхняя панель выключается отдельно.

## Что пока НЕ исправлено и НЕ проверено

- Центральные вкладки по прототипу baldierot ещё не перенесены. Портретная
  ориентация намеренно не включена до адаптации основной раскладки.
- Однопальцевая прокрутка текста, выделение с маркерами, клавиатура/IME,
  конфликты тап/перетаскивание не считаются исправленными.
- Достижимость всех инструментов 2D/3D, работа всех плагинов, сохранение
  при сбое и удобство на Redmi Note 13 требуют отдельных проверок.
- Автоматические проверки исходников и успешная компиляция — не независимая QA
  и не подтверждение удобства на телефоне.

## Подпись, резервная копия и откат

Пакет: `org.godotengine.editor.v4.phonepreview1.debug` или `.release`.
Название: **Godot Phone Preview 1**. Не заменяет официальный Godot и SAF Test.
Используется автоматически созданная тестовая подпись среды GitHub, без доступа
к секретам репозитория. Постоянный ключ редактора не подтверждён и не сохранён:
совместимость последующих обновлений по подписи НЕ гарантируется. Прежде чем
переходить к длительной работе, нужен отдельно сохранённый постоянный ключ.
Ключ игры для этого не нужен; не публиковать его, пароли или проект игры.

До открытия проекта в Preview сделать его отдельную копию на телефоне.
Не открывать единственный рабочий экземпляр: разные приложения могут изменять
одни и те же общие файлы, несмотря на разные Android package ID.
Не удалять установленный Godot/GABE, их данные, Rootfs или кэш.

Откат: закрыть Preview и вернуться к прежнему Godot и нетронутой копии проекта.
Это не восстанавливает файлы, если они были изменены в общей исходной папке,
поэтому копия проекта обязательна. Автоустановка и публикация релиза не выполняются.

## Проверка на Redmi Note 13

- Установить отдельно; убедиться, что прежние приложения остались.
- На копии диагностического проекта проверить основные кнопки, поля чисел,
  Scene/Inspector/FileSystem, всплывающие меню, доступ к правому краю верхней панели.
- Открыть длинный скрипт, прокрутить двумя пальцами в обе стороны: без прыжков,
  без изменения текста; затем проверить сохранность обычного выделения и ввода.
- Проверить открытие/закрытие клавиатуры, Undo/Redo, сохранение и повторное открытие.
- Снять короткую запись проблемных мест. До этого статус UX: NOT_TESTED_ON_DEVICE.

https://github.com/godotengine/godot-proposals/issues/13945
Его демонстрационный код не переносился целиком и не считается проверенным.

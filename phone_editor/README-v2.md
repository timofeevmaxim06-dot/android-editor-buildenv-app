# Godot Phone Preview 2 — кандидат исправления раскладки

Preview 1 не прошёл проверку удобства на телефоне: принудительные размеры
общих кнопок/полей/строк и старая раскладка дали переполнение и обрезку.
Его успешная компиляция и подпись не доказывали качество интерфейса.

## Изменения кандидата

- Убрано глобальное увеличение Button, LineEdit, Tree и стилей вкладок/меню.
- В режиме телефона снижен настольный минимум окна 1024×600 × масштаб,
  чтобы проверять узкие окна на Linux. Android игнорирует этот предел главного
  окна; его влияние на обрезку первой Android-сборки не подтверждено.
- Боковые вертикальные панели собраны штатным DockManager в центральные вкладки.
  Рабочее поле и панели показываются по очереди. Кнопки «Редактор», «Сцена»,
  «Файловая система», «Инспектор» доступны в одной переносимой строке.
- Вкладки Import, Signals, Groups, History остаются в штатном контейнере.
- Для минимального размера учитывается выбранная вкладка, а не все скрытые.
- Верхняя панель Android сохраняет горизонтальную прокрутку при нехватке ширины.
- Прежний пересчёт двухпальцевой прокрутки сохранён. Исправление однопальцевого
  выделения, IME и всех сенсорных жестов НЕ заявляется.
- Сохранены обычные размеры элементов и штатная панель Save/Undo/Redo.
  Дальнейшее увеличение отдельных кнопок допускается после проверки раскладки.

Мобильная раскладка включается настройкой
`interface/touchscreen/phone_single_panel_mode` с перезапуском. На Android
она включена по умолчанию; на Linux включается только для проверки.
Портретный режим пока не включён. Переход из файлов к уже открытому редактору
доступен кнопкой «Редактор»; автоматическое переключение всех сценариев не заявляется.

## Проверка перед Android-сборкой

Сначала собирается настольный редактор с тем же кодом DockManager. На отдельном
синтетическом проекте включаются русский язык и масштабы 150%/200%.
Проверяются окна 1920×864 и 1536×691, переключение редактора/сцены/файлов/инспектора,
положение рабочих областей внутри окна и сохранение не менее половины высоты
под активную рабочую область. Сохраняются снимки настоящего интерфейса и JSON.

Эта проверка не воспроизводит сенсорный ввод Android, его отдельную верхнюю
панель и клавиатуру. Она не заменяет проверку на Redmi. APK не собирается,
если проверка общей раскладки не пройдена. Статус конкретного запуска смотреть
в GitHub Actions; наличие этого файла не означает PASS.

## Безопасная установка

Новый пакет `org.godotengine.editor.v4.phonepreview2.debug` (либо `.release`)
устанавливается отдельно. Старые Godot, GABE и данные приложения не заменяются.
Используется тестовая подпись среды сборки; постоянный ключ пока не сохранён,
совместимость будущих обновлений по подписи не гарантируется.

Тестировать только отдельную копию проекта. Разные Android package ID
не защищают общий файл проекта от изменений. Для отката закрыть Preview 2
и вернуться к прежнему Godot и нетронутой копии. R3-09 остаётся на паузе.

Основа: Godot 4.7.2 `ed1daf0bf001b61586d9930840f2f1394092c079`.
Шаблоны экспорта и сама игра не изменяются. Ключ игры не используется.

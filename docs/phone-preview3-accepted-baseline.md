Дата фиксации: 14 сентября 2026 года.

Preview 3 принята пользователем как удобная основа для дальнейшей небольшой
доработки. Размещение панелей устраивает. Замечание: текст в горизонтальной
ориентации хотелось бы крупнее. Это общая оценка работы на телефоне; отдельное
прохождение каждого сценария IME, выделения и буфера обмена не заявлено.

## Граница следующего изменения

Preview 3.1 сохраняет принятую раскладку и существующий порядок команд.
Единственная функциональная дельта в исходниках редактора — кнопки изменения
шрифта в конце панели кода. Они вызывают штатные операции масштабирования.
Алгоритмы сенсорного ввода, доки, создание узлов и размеры панелей не меняются.

Размер шрифта доступен и в принятой версии через настройки редактора. Значение
18 вместо 14 — исходная рекомендация для подбора, не результат измерения зрения
или утверждение об удобстве для каждого пользователя.

Новая сборка, когда её проверки завершатся, оценивается по собственному запуску.
Результат принятой основы не выдаётся за результат 3.1.

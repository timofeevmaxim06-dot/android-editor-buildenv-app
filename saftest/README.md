# Изолированная тестовая пара

Это не официальный выпуск и не подтверждённое исправление для устройства.
GABE основана на 8d390ffe73e60ebf9e719249fb964bfca0f77b9f.
Godot 4.7.2 основан на ed1daf0bf001b61586d9930840f2f1394092c079.

Пакеты: `org.godotengine.godot_gradle_build_environment.saftest` и
`org.godotengine.editor.v4.saftest.release` (либо `.debug`).
Официальные приложения остаются установленными. Подписи тестовые, создаются
сборочной средой; ключ игры не используется. Повторная сборка может иметь другую подпись.

GABE перенаправляет только copyAndRenameBinary во внутреннюю уникальную папку.
После успеха копирует результат через SAF в пределах ранее разрешённой папки
проекта и сверяет размер и SHA-256. Существующий файл не перезаписывается.
При ошибке новый неполный файл удаляется по возможности, внутренняя копия остаётся.
Другие сборочные задачи не перенаправляются; XR не изменяется.

Перед тестированием сделать отдельную копию диагностического проекта на телефоне.
Не удалять официальную GABE, её Rootfs или кэш. Новая GABE имеет отдельные данные:
Rootfs и разрешение на папку потребуется настроить заново. Выбрать новое имя AAB.
Не загружать на GitHub игру, keystore, пароли или полные журналы с ними.

Критерий проверки на устройстве: успешная сборка, сообщение SAF export completed
and SHA-256 verified, непустой AAB в выбранной папке. Затем повторный экспорт с
другим именем. Автоматические тесты проверяют маршрутизацию путей, но не заменяют
проверку Android DocumentProvider на устройстве.

Сборка запускается в отдельной ветке; основная ветка и официальный репозиторий
не меняются. Исходные лицензии сохраняются в репозиториях.
